# 🌟 Полный список возможностей AI Eye Blink Checker

## ✅ Основные функции

### 👁️ Детекция моргания
- **Алгоритм**: Eye Aspect Ratio (EAR) + MediaPipe Face Mesh
- **Точность**: >95% при хороших условиях освещения
- **FPS**: 25-30 кадров/секунду
- **Латентность**: ~30-40 мс на кадр

### ⏱️ Режимы работы
- **Бесконечный режим** (по умолчанию): работает до нажатия 'q' или ESC
- **Таймер**: указать время в секундах через `--time`
- **Гибкая настройка**: любая комбинация параметров

### 🚨 Звуковой сигнал (Alarm)
- **Назначение**: напоминание моргнуть при длительном отсутствии моргания
- **Настройка**: `--alarm N` (N секунд без моргания)
- **Индикация**: 
  - Звуковой сигнал (системный beep)
  - Сообщение в консоли
  - Изменение цвета таймера на красный
- **Рекомендации**:
  - Работа за компьютером: 10 секунд
  - Чтение/концентрация: 15 секунд

### 📊 График морганий в реальном времени
- **Типы**:
  - Столбчатая диаграмма частоты моргания
  - Группировка по 1 или 5 минутам
- **Визуализация**:
  - 🟢 Зеленый: норма (≥10 морганий/интервал)
  - 🟠 Оранжевый: низко (5-9 морганий)
  - 🔴 Красный: очень низко (<5 морганий)
  - Линия нормальной частоты
- **Статистика**: общее количество, частота, время
- **Автосохранение**: PNG файл при завершении

## 📋 Параметры командной строки

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|----------------------|----------|
| `--time`, `-t` | int | 0 (бесконечно) | Время мониторинга в секундах |
| `--camera`, `-c` | int | 0 | Индекс камеры |
| `--alarm` | int | 0 (выкл) | Порог для звукового сигнала (сек) |
| `--plot` | flag | False | Показать график |
| `--plot-interval` | int | 1 | Группировка графика (1 или 5 мин) |
| `--no-display` | flag | False | Режим без видео (headless) |

## 🎯 Варианты использования

### 1. Базовый мониторинг
```bash
uv run blink-checker
```
Бесконечная работа с визуализацией ключевых точек глаз.

### 2. Работа за компьютером (рекомендуется)
```bash
uv run blink-checker --plot --alarm 10
```
График + напоминания каждые 10 секунд.

### 3. Длительная сессия с анализом
```bash
uv run blink-checker --plot --plot-interval 5 --alarm 15
```
График с группировкой по 5 минут + мягкие напоминания.

### 4. Быстрый тест
```bash
uv run blink-checker --time 60
```
Мониторинг 1 минуту, получить статистику.

### 5. Фоновый режим
```bash
uv run blink-checker --no-display --plot --alarm 10
```
Без видео, только график и напоминания.

### 6. Исследование и сбор данных
```bash
uv run blink-checker --time 600 --plot --plot-interval 1
```
10 минут детального мониторинга с сохранением графика.

## 🔬 Технические детали

### Алгоритм EAR
```
EAR = (||p2-p6|| + ||p3-p5||) / (2*||p1-p4||)

Где:
- p1-p6: 6 ключевых точек глаза
- Открытые глаза: EAR ≈ 0.25-0.35
- Закрытые глаза: EAR ≈ 0.10-0.20
- Порог: 0.21
```

### Параметры детекции
- **EAR_THRESHOLD**: 0.21
- **CONSECUTIVE_FRAMES**: 2 (для подтверждения)
- **Разрешение камеры**: 640x480
- **FPS**: 30

### Интерпретация частоты
| Частота (раз/мин) | Статус | Описание |
|------------------|--------|----------|
| 10-25 | ✅ Нормально | Здоровое состояние |
| < 10 | ⚠️ Низкая | Усталость, концентрация |
| > 25 | ⚠️ Высокая | Стресс, раздражение |

**Важно**: При работе за компьютером частота часто падает до 5-7 раз/мин → синдром сухого глаза.

## 💡 Советы по использованию

### Для лучшей точности
1. ✅ Хорошее фронтальное освещение
2. ✅ Лицо прямо к камере
3. ✅ Расстояние 50-70 см
4. ✅ Стабильное положение головы
5. ❌ Избегать задней подсветки
6. ❌ Не носить темные очки

### Для здоровья глаз
- Используйте `--alarm 10` при работе за компьютером
- Делайте перерывы каждые 20-30 минут
- Следите за графиком - красные зоны = проблема
- Стремитесь к 15-20 морганиям в минуту

### Для анализа данных
- Используйте `--plot-interval 1` для детального анализа
- Сохраняйте графики для сравнения разных сессий
- Обращайте внимание на паттерны в течение дня
- Корректируйте рабочие привычки на основе данных
