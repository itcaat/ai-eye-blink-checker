# 👁️ AI Eye Blink Checker

Приложение для определения моргания глаз с использованием камеры и AI в реальном времени.

## Описание

Использует компьютерное зрение (MediaPipe + OpenCV) и алгоритм Eye Aspect Ratio (EAR) для обнаружения и подсчета моргания. Полезно для мониторинга усталости глаз при работе за компьютером.

**Основные возможности:**
- ✅ Детекция моргания в реальном времени
- ✅ Бесконечный режим или с таймером
- ✅ 🚨 Звуковой сигнал при редком моргании
- ✅ Статистика: частота моргания, оценка состояния
- ✅ Визуализация ключевых точек глаз

## Использование

### Базовое использование

```bash
# Бесконечный режим (нажмите 'q' или ESC для остановки)
uv run blink-checker

# С ограничением по времени
uv run blink-checker --time 30
uv run blink-checker --time 60
```

### Параметры

| Параметр | Описание | Пример |
|----------|----------|--------|
| `--time`, `-t` | Время в секундах (0 = бесконечно) | `-t 60` |
| `--camera`, `-c` | Индекс камеры | `-c 1` |
| `--alarm` | 🚨 Сигнал, если N секунд нет моргания | `--alarm 10` |
| `--no-display` | Режим без GUI | `--no-display` |

### Примеры

```bash
# Мониторинг во время работы с напоминанием моргать
uv run blink-checker --alarm 10

# Быстрый тест 10 секунд
uv run blink-checker -t 10

# Работа с сигналом при отсутствии моргания 15 секунд
uv run blink-checker --alarm 15

# Использовать внешнюю камеру
uv run blink-checker --camera 1

# Режим без GUI с сигналом
uv run blink-checker --time 60 --alarm 10 --no-display
```

## Как это работает

### Алгоритм EAR (Eye Aspect Ratio)

1. **MediaPipe Face Mesh** обнаруживает 468 точек на лице
2. Извлекаются 6 ключевых точек для каждого глаза
3. Вычисляется EAR: `(||p2-p6|| + ||p3-p5||) / (2*||p1-p4||)`
4. Когда EAR < 0.21 → глаза закрыты → моргание

### Интерпретация результатов

| Частота моргания | Статус | Описание |
|-----------------|--------|----------|
| 10-25 раз/мин | ✅ Норма | Здоровое состояние |
| < 10 раз/мин | ⚠️ Низкая | Усталость, концентрация |
| > 25 раз/мин | ⚠️ Высокая | Стресс, раздражение глаз |

**Важно:** При работе за компьютером частота моргания часто снижается до 5-7 раз/мин, что может привести к синдрому сухого глаза.

### Функция Alarm 🚨

Приложение может подавать звуковой сигнал, если вы долго не моргаете:

```bash
# Сигнал каждые 10 секунд без моргания
uv run blink-checker --alarm 10

# Более терпимый режим - 15 секунд
uv run blink-checker --alarm 15
```

**Что происходит:**
- ⏰ Отслеживает время с последнего моргания
- 🔴 Цвет таймера меняется на красный при превышении порога
- 🚨 Звуковой сигнал + сообщение в консоли
- ✅ Сброс после моргания

**Рекомендуемые настройки:**
- **Работа за компьютером:** `--alarm 10` (каждые 10 секунд)
- **Чтение/концентрация:** `--alarm 15` (каждые 15 секунд)
- **Без напоминаний:** не указывайте `--alarm` (по умолчанию)

## Устранение проблем

### Камера не работает
```bash
# Попробуйте другой индекс камеры
uv run blink-checker --camera 1
```

### Моргания не обнаруживаются
- Убедитесь в хорошем освещении (избегайте задней подсветки)
- Держите лицо прямо к камере на расстоянии 50-70 см
- Моргайте полностью (закрывайте глаза на 100%)

### Альтернативная установка (без uv)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m blink_checker.main
```

## Программное использование

```python
import cv2
from blink_checker.detector import BlinkDetector

detector = BlinkDetector()
cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break
    
    blink_detected, ear, annotated_frame = detector.detect_blink(frame)
    
    if blink_detected:
        print(f"Моргание! Всего: {detector.get_blink_count()}")
    
    cv2.imshow("Blink Detection", annotated_frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

Больше примеров в `example_usage.py`.
